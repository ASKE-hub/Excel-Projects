## Excel features in this collection

- **PivotTables:** summaries across sales, complaints, electronics, manufacturing, and development data.
- **Charts:** visual reporting in six workbooks.
- **Excel tables:** structured datasets in the flights and restaurant workbooks.
- **Dashboards and report sheets:** dedicated views supported by underlying data.
- **Data documentation:** an employee survey data dictionary.

## Getting started

1. Download a workbook from the catalog, or use **Download all workbooks** above and extract the ZIP.
2. Open the `.xlsx` file in Microsoft Excel desktop.
3. Start with the worksheet listed in the catalog, then explore the supporting data and reports.
4. To refresh a workbook, first review **Data → Queries & Connections** and update any source paths required by your local setup.

GitHub hosts the files; open them in Excel to explore workbook features. Other spreadsheet applications may display Excel-specific features differently.

To clone the collection with Git:

```bash
git clone https://github.com/ASKE-hub/Excel-Projects.git
```

## About this repository

The primary project files are Microsoft Excel (`.xlsx`) workbooks. GitHub's language statistics use [Linguist](https://github.com/github-linguist/linguist), which does not define Excel as a language. An empty language bar is therefore expected for this collection.
